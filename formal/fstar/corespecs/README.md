# corespecs

Normative or near-normative material laid out by external standards bodies:
W3C RDF Concepts, RDF Semantics, SPARQL Query, SPARQL Protocol, OWL profiles,
IETF URI/IRI-related algorithms, and similar documents.

This bucket should read as a mathematical/specification shadow first. It may
contain executable definitions when the specification itself is algorithmic,
but parser shortcuts, storage layout, extraction workarounds, and deployment
policy should not live here.
