# ocaml-output — F*-extracted OCaml + test harness

This directory contains OCaml source files **extracted from F\*** plus
hand-written I/O glue for testing.

## Extracted modules (from F\*)

These are generated by `fstar.exe --codegen OCaml` — do not edit by hand.

| File | F\* source | Purpose |
|------|-----------|---------|
| `RDF_Graph_Executable.ml` | `RDF.Graph.Executable.fst` | RDF graph types and operations |
| `SPARQL11_Algebra.ml` | `SPARQL11.Algebra.fst` | SPARQL 1.1 algebra + evaluator |
| `SPARQL11_Parser.ml` | `SPARQL11.Parser.fst` | SPARQL query parser |
| `Parser_Combinators.ml` | `Parser.Combinators.fst` | Monadic parser combinator library |
| `Parser_NTriples.ml` | `Parser.NTriples.fst` | N-Triples parser |
| `Parser_Turtle.ml` | `Parser.Turtle.fst` | Turtle parser |
| `Parser_NQuads.ml` | `Parser.NQuads.fst` | N-Quads parser |
| `Parser_TriG.ml` | `Parser.TriG.fst` | TriG parser |
| `Parser_XML.ml` | `Parser.XML.fst` | Non-validating XML parser |
| `Parser_RDFXML.ml` | `Parser.RDFXML.fst` | RDF/XML parser |
| `Parser_SRX.ml` | `Parser.SRX.fst` | SPARQL Results XML parser |
| `Parser_CSVResults.ml` | `Parser.CSVResults.fst` | CSV/TSV results parser |

## Hand-written files

| File | Purpose |
|------|---------|
| `w3c_runner.ml` | W3C conformance test runner (I/O glue) |
| `factoidal_cli.ml` | `factoidal` CLI tool (arq-like SPARQL query interface) |
| `fstar_int_stubs.js` | js_of_ocaml integer stubs for bigint support |

## Building

From the parent directory (`formal/fstar/`):

```bash
eval $(opam env --switch=fstar)

# Extract from F* + compile + test:
./build-ocaml.sh

# Or just compile (after extraction):
./build-ocaml.sh compile
```

This produces native executables in this directory:
- `factoidal` — SPARQL query CLI
- `w3c_runner` — W3C conformance test runner

## Note on binary artifacts

The `.cmi`, `.cmx`, `.o` files and native executables are **not committed**.
They are platform-specific build artifacts regenerated by `build-ocaml.sh`.
See `.gitignore` in this directory.
