## Verdict

**The tree rebuilds from a bare clone.** Cold F\* verify + extract, OCaml
compile, and every advertised conformance suite all exited 0, from a clone
with zero `.checked` files, zero extracted `.ml`, zero committed binaries
and no extraction manifest. This is the first time that has been
demonstrated end to end; until now every published score carried an
unstated dependency on accumulated build state.

Cost of the cold path, on 4 cores at `BUILD_JOBS=4`:

for the verification itself. The suites, not the proofs, dominate a cold
run.

  `./build-ocaml.sh compile` from a fresh clone without extracting first
  does not. Anti-pattern #27 shape.

  `.gitignore` entry calling it "local build-cache state, not a committed
  artifact". That is what made #320's soundness gap repo-wide rather than
  dev-loop-only.

## Caveats on this run

- **Test fixtures were copied** from an existing checkout rather than
  fetched as submodules. Fixtures are test *inputs*; the build does not
  produce them. Nothing built here came from the source checkout.
- **Shallow clone**, for the reason above.
- The **toolchain is an input**, not something this run reproduces: F\*
  2025.12.15, z3 4.13.3, OCaml 4.14.1, from the existing opam switch.
- The JS/wasm bundles were not rebuilt (`build-ocaml.sh js` / `wasm` are
  not in this path), so hub cells ran against the committed bundle —
  hazard #12 applies to any future claim made from this artifact about
  browser behaviour.
