What This Proves

The same F* specification that the typechecker verifies is also the source code for the running engine. The JavaScript you see here was extracted from verified F* — not hand-written. This is the same approach used by HACL* (crypto in Firefox/Linux kernel) and EverParse (parsers in Windows Hyper-V).

Build Locally

# Prerequisites: opam switch fstar, F* 2025.12.15, js_of_ocaml
eval $(opam env --switch=fstar)

# Full pipeline: extract + compile + test + JS
cd formal/fstar
./build-ocaml.sh

# Individual steps
./build-ocaml.sh extract   # F* → OCaml
./build-ocaml.sh compile   # OCaml → native binaries
./build-ocaml.sh test      # Run native tests
./build-ocaml.sh js        # OCaml → JavaScript
