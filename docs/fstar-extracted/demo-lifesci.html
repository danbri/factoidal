What's running under the hood

Three Turtle files are fetched from this page's lifesci/ subdirectory (~1.4 MB total), parsed by the F*-verified Turtle parser, and loaded into three named graphs keyed as urn:kgx:chromosome, urn:kgx:sequence_variant, and urn:kgx:disease. SPARQL queries use GRAPH <urn:kgx:…> { … } to select per graph.

The larger gene.ttl (17 MB, 889k triples) that sits next to these three in the repo is intentionally not loaded here — parsing 889k triples in the browser is slow and the naive BGP evaluator on a list-backed graph is not yet fast enough to make the disease↔gene join interactive. That is what the indexed in-memory store work is about. For now, see examples/wikidata/subsets/lifesci-kgx/ in the repo for how to run it natively.
