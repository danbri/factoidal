Factoidal — notebook-style SPARQL v3 · Notebook

Multiple <factoidal-sparql-client> instances stacked as cells. Each cell runs independently; new result views (Table / JSON / CSV / TSV), downloadable result files, per-column hide, numeric right-alignment, and Ctrl+Enter to run. v2 demo · v1 demo · index

Cell 1 — Top diseases by gene count

# Which diseases have the most known genetic associations? # Returns (?disease, ?associated_genes). ?associated_genes is an # xsd:integer — the column should be right-aligned with tabular-nums # in the Table view. PREFIX wdt: <http://www.wikidata.org/prop/direct/> SELECT ?disease (COUNT(?gene) AS ?associated_genes) WHERE { GRAPH <urn:kgx:disease> { ?disease wdt:P2293 ?gene } } GROUP BY ?disease ORDER BY DESC(?associated_genes) LIMIT 10

Cell 2 — Variants × chromosomes

# For each sequence variant, which chromosome is it located on? # Two IRI columns; both should show as clickable wd:Q... abbreviations. # Try the column-hide button (the "x" on a column header) to hide # ?variant and see just the chromosome list. PREFIX wdt: <http://www.wikidata.org/prop/direct/> PREFIX wd: <http://www.wikidata.org/entity/> SELECT ?variant ?chrom WHERE { GRAPH <urn:kgx:chromosome> { ?chrom wdt:P31 wd:Q37748 } GRAPH <urn:kgx:sequence_variant> { ?variant wdt:P1057 ?chrom } } LIMIT 20

Cell 3 — Graph sizes

# Triple count per named graph — a tidy two-column result with an # IRI (?g) and an integer (?triples). Try switching to the JSON / CSV # / TSV view; the Download buttons offer the same data as files. PREFIX xsd: <http://www.w3.org/2001/XMLSchema#> SELECT ?g (COUNT(*) AS ?triples) WHERE { GRAPH ?g { ?s ?p ?o } } GROUP BY ?g ORDER BY DESC(?triples)
What's new in this demo:
  • Multiple query cells on one page, each with its own engine state, run button, and result view.
  • Result view tabs: Table, JSON, CSV, TSV.
  • Download buttons for JSON / CSV / TSV of the last result. CSV/TSV are client-side formatters; when the F* engine gains a canonical -o csv path, we can switch to that.
  • Column-kind inference: integer columns right-align with tabular numerals; date/dateTime literals render cleaner (raw ISO kept on title=).
  • Per-column hide (x on the header); show all link to reset.
  • Ctrl+Enter (Cmd+Enter on macOS) runs the query from inside the editor.
