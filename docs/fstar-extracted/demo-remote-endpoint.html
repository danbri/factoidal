factoidal-sparql-client — remote SPARQL Protocol demo

This page passes endpoint=... to the component, which then bypasses the in-browser engine and POSTs queries to the remote endpoint (application/sparql-query with Accept: application/sparql-results+json).

SELECT (COUNT(*) AS ?n) WHERE { ?s ?p ?o } SELECT ?s ?p ?o WHERE { ?s ?p ?o } LIMIT 10 SELECT ?type (COUNT(*) AS ?n) WHERE { ?s a ?type } GROUP BY ?type ORDER BY DESC(?n) LIMIT 20
