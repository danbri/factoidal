factoidal SPARQL endpoint

Verified RDF/SPARQL 1.1 service. Protocol endpoint at /sparql. This page is a generic SPARQL playground using <factoidal-sparql-client> as a W3C SPARQL 1.1 Protocol client; programmatic clients should hit /sparql directly per SPARQL 1.1 Protocol.

Per-dataset demos are available with the --web-demo <id> flag, e.g. --web-demo ukparliament. Demo directories live under docs/web/demos/<id>/; to author a new demo, drop an index.html there (no recompile).

SELECT (COUNT(*) AS ?n) WHERE { ?s ?p ?o } PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> SELECT DISTINCT ?cls WHERE { ?s rdf:type ?cls } ORDER BY ?cls LIMIT 25 SELECT ?p (COUNT(*) AS ?n) WHERE { ?s ?p ?o } GROUP BY ?p ORDER BY DESC(?n) LIMIT 25
Per-query timing is in the Details pane below the results table. The component sends POST /sparql with Content-Type: application/sparql-query and Accept: application/sparql-results+json.
Operator views: /admin (live recent-queries dashboard) · /admin/recent.json (raw) · /backend-info.json (loaded data).
