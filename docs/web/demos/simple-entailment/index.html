simple entailment demo

Tiny dataset (simple.ttl) for exercising RDF / RDFS entailment regimes against the verified evaluator. Useful for checking that rdf:type propagation and rdfs:subClassOf closure behave the way the F* spec says they do, without the noise of a full corpus.

Launch with: factoidal-http --dataset simple.ttl --web-demo simple-entailment.

SELECT (COUNT(*) AS ?n) WHERE { ?s ?p ?o } PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> SELECT ?s ?cls WHERE { ?s rdf:type ?cls } ORDER BY ?s PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#> SELECT ?sub ?super WHERE { ?sub rdfs:subClassOf ?super } ORDER BY ?sub PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#> SELECT ?p ?dom ?rng WHERE { ?p rdfs:domain ?dom . OPTIONAL { ?p rdfs:range ?rng } } ORDER BY ?p
This demo focuses on schema-level facts so an entailment regime toggle (RDFS / OWL-RL) can be wired in via a query-string param later. For now everything runs under simple entailment.
