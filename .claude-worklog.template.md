# Claude session worklog — template

Per CLAUDE.md rule #18: the live copy is `.claude-worklog.md` (gitignored).
Duplicate this file to that path at the start of a session and keep it up
to date after every material change and before every long-running tool call.

## CURRENT STATE

_Overwrite this section on every checkpoint._

- **Timestamp (UTC):** YYYY-MM-DDTHH:MM:SSZ
- **Session goal (one line):**
- **Last completed step:**
- **Next step planned:**
- **In-flight processes:**

  - (or: `<op>` — PID `<pid>`, log `.claude-runs/<name>.log`, started `<T>`, cap `<N>s`)
- **Uncommitted changes (`git status` summary):**

- **Known regressions / blockers:**

## HISTORY

_Append one bullet per checkpoint. Newest on top so a fresh session sees
the most recent work first. Keep each entry tight — the transcript has
the details; this file is just the spine._

- `YYYY-MM-DDTHH:MM:SSZ` — what just finished, what I'm about to do, any
  surprise. Include PIDs / log paths for background processes.
